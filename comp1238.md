## Week 1 - History
- understanding the history of even non-digital data management is useful to understanding the now digitized world of it today
- Babylonian used a **base-60 system** similar to our modern base-10
- **Gutenberg press** revolutionized printing at the time.
- **monospace** made for typewriters. usually hat's used with coding
- **typeface** is a design of letters, **font** is a collection of typefaces

## Week 2 - Bits and Bytes
- a **bit** is 1 digit, a **nibble** is 4, and a **byte** is 8.
- the **ASCII table** maps numbers to characters.
- **Unsigned Numbers** range from 0 to 255, while **Signed Numbers** range from -128 to 127 (both for 8 bits.)
Fractional Numbers

## Week 3 - Markup Languages
- already familiar with **MarkDown** as I use it to write with (on Obsidian)
- **JSON** is usually used for data exchange
- **XML** is similar to HTMl. Used for data representation
- **Unicode:** ASCII codes? no, Unicode **codepoints.** Functions like ASCII, assigning numbers to characters.
  - **UTF-32** uses 4 bytes, wasted a lot of space since a lot of the digits end up being 0
  - **UTF-8** is identical to ASCII for basic characters, but uses multiple bytes for codepoints above 127

## Week 4 - Keyboards & Editors
- lots of different layouts and types of **keyboards**
  - **size:** full-size (100%), TKL (80%), etc
  - **layout:** QWERTY is the widespread most popular for English
  - different keyboard may have different **modifier keys.** This is even more true when computers were a newer thing.
  - **mechanical keyboards** are highly customizable, able to choose between stuff like switches and keycap profiles
- **Text Editors** like Notepad and **Word Processors** LibreOffice Writer
  - **Vim** (my enemy) is a popular editor
- **IDE** means Integrated Development Environments. Think stuff like Eclipse
- slight introduction to **Regex**

## Week 5 - CLI
- originally code was printed onto paper instead of displayed onto a screen, only later did monitors become a widespread thing
- and even later still were the rise of **GUIs**, for a long time computers were just a console terminal on a screen (think the scene with Flynn and Clu in the original Tron movie, haha)
- the majority of servers run on **Linux,** so it's best to get used to a **UNIX terminal**
  - I have 2 profiles on Konsole (on Arch), one running a **bash** shell and one running a **fish** shell
- not completely necessary for the midterm, but it's good to get a grasp of very simple and common terminal commands
  - ls : list
  - cd : change directory
  - pwd : print working directory
  - cat : display file contents
  - less : display file contents interactively
  - cp : copy (files)
  - mv : move (files)
  - mkdir : make directory
  - ping : test network connectivity
  - grep : search text using patterns
  - ssh : secure shell
  - scp : secure copy (between computers)
  - sftp : secure file transfer protocol
  - htop : monitor processes and resource usage
  - tmux : terminal multiplexer
